\section{How to Use This Chapter}
\label{sec:qna-intro}

Each section is a run of question-and-answer pairs grouped by subject. The
answers are deliberately concise: state the definition, the key
distinction, and one example or ``why it matters,'' which is exactly the
shape of a strong verbal answer. Read them as flashcards -- cover the
answer, attempt it aloud, then check.

\begin{ideabox}[Answer Structure That Impresses]
For any ``what is X / difference between X and Y'' question, answer in
three beats: (1) a one-sentence definition, (2) the crucial distinction or
property, (3) a concrete example or consequence. Rambling loses points;
this three-beat shape signals clarity.
\end{ideabox}
